# 2026-05-03

## 修复：FileReceiverPlugin 未注册导致微信文件无法打开

**根因**：`capacitor.plugins.json` 只列出 npm 安装的插件，自定义的 `FileReceiverPlugin` 不在其中。`PluginManager.loadPluginClasses()` 只从该 JSON 加载插件，导致 `getBridge().getPlugin("FileReceiver")` 返回 null。

**修复**：`MainActivity.java` 添加 `registerPlugin(FileReceiverPlugin.class)` 在 `super.onCreate()` 前调用。
